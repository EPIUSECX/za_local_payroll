# Security policy

Payroll data is highly sensitive. Never put employee identity, tax, banking,
salary, benefit, directive or certificate data in public issues. Report suspected
vulnerabilities privately to the maintainers with the affected version,
reproduction and impact.

Use least privilege, maker/checker payment controls, encrypted backups and
restricted private files. Supported fixes target the pinned Frappe/ERPNext/HRMS
v16 release line.
